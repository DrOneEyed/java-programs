# Java Programs

A collection of Java lab exercises, servlet examples, and theory assignments covering core Java programming and web development with servlets.

## Structure

| Folder | Description |
|--------|-------------|
| `Java_Lab_CAT` | CAT (Continuous Assessment Test) lab programs |
| `Lab_1` | Introductory Java lab exercises |
| `serlet_ex1` | Java Servlet example — request/response handling |
| `Theory_DA1` | Theory assignment 1 — Java concepts and programs |
| `web_exp` | Web development experiments with Java servlets |

## Getting Started

```bash
git clone https://github.com/DrOneEyed/java-programs.git
cd java-programs
# Compile any .java file:
javac FileName.java && java FileName
# For servlet examples, deploy to Apache Tomcat
```

## Topics Covered

- OOP principles (classes, objects, inheritance, polymorphism)
- Exception handling
- Collections and generics
- File I/O
- Java Servlets and HTTP request/response lifecycle
- HTML form handling with servlets
